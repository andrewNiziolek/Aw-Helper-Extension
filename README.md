# Awin Helper

This is a community-developed extension to support Awin Staff in their daily responsibilities.


## Installation

[Chrome Webstore](https://chrome.google.com/webstore/detail/awin-helper/ddfnphknakdknhcolehloanbkeppaomo?hl=en&authuser=0)

[Edge Webstore](https://microsoftedge.microsoft.com/addons/detail/awin-helper/bjlmofgpijnhhaclcifnjnafjmdehncl)

## General Use Instructions

To use the Awin Helper Extension, install the extension from the Google or Microsoft Webstore.

When installed, you'll see the extension in your toolbar or in the extensions submenu. Pinning it to your toolbar is recommended.

Click the icon to open **Glance**, a quick summary of the site you're on.

For more detail, click **Open Dock** to launch the side panel. Dock stays open and updates as you switch tabs.

## Contributing

To contribute to this project, please fork the project from the `main` branch and make your changes on a new branch.

There's no build step. The extension is plain JavaScript, HTML, and CSS (Manifest V3). To test your changes locally:

1. Go to `chrome://extensions` (or `edge://extensions` in Edge).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select your project folder.
4. After making changes, click the reload icon on the extension card.

Once you've completed your code changes, please open a Pull Request that outlines the changes and confirms you've tested the extension in your browser to ensure compliance with Manifest V3.

If approved, your Pull Request will be merged for use on the next release.
